# RSSI Reference

RSSI is shown in dBm, which means "decibels relative to 1 milliwatt."

For Wi-Fi it is usually negative:

- `-30 dBm` = excellent, very close
- `-50 dBm` = strong
- `-67 dBm` = good/usable
- `-80 dBm` = weak
- `-90 dBm` = barely usable

So an `RSSI -50 dBm` reading is a strong signal.
